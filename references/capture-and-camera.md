# 录制、匿名与摄像机

## 真实操作与时间

`assets/record-template.cjs` 导出录制函数，可由项目适配脚本调用：

```js
const record=require('/absolute/skill/assets/record-template.cjs');
record({
 project:'/absolute/output',url:'https://chosen-product.example',
 width:1440,height:800,
 setup:async context=>{ /* 使用用户已授权会话，按产品实际方式登录 */ },
 actions:async({p,scene,click})=>{
  await p.locator('main').waitFor();
  await scene('search',async()=>{
   await click(p.getByRole('button',{name:'查导师',exact:true}));
   // 按实际产品继续输入、选取结果；不要照抄别的项目选择器。
  },[{q:0,z:1,x:720,y:400},{q:.25,z:1.5,x:720,y:390},{q:1,z:1.15,x:720,y:430}]);
 }
});
```

录制模板启用 `bypassCSP` 仅用于本地鼠标/匿名展示层，不更改线上 CSP。使用范围只限这次录制浏览器上下文。选择器、业务身份、URL 与认证代码留在项目适配器中，不能固化到通用技能。

模板的 `capture-draft.json` 使用墙钟估算，Playwright 录像首次出帧、导航和关闭可能造成与 WebM PTS 的偏移。必须用 `ffprobe` 查总长，并抽帧对齐每个点击/结果出现点，再写 `capture.json`。补录短片尤其容易出现整段偏移；不能只按结束时长推断全部时间都正确。严重漂移时按实际镜头内容重定切点；不要把超过源文件末尾的片段交给 FFmpeg 隐式停帧。

等待异步生成的时间应单独剪除，不把生成等待和后续操作一起极限加速。生成按钮和真实结果都要保留，必要时分两个分镜。使用录制浏览器里的真实返回，不拦截 API 填造成功结果。

## capture.json

```json
{
 "width":1440,"height":800,
 "clips":[{
  "id":"search","sourceVideo":"screen-recording.webm","start":8.4,"end":13.1,
  "camera":[
   {"q":0,"z":1,"x":720,"y":400},
   {"q":0.25,"z":1.6,"x":720,"y":380},
   {"q":0.8,"z":1.6,"x":720,"y":440},
   {"q":1,"z":1.1,"x":720,"y":420}
  ]
 }]
}
```

- `start/end`：源媒体的秒数，不是配音时间或最终视频时间。
- `sourceVideo`：相对 `assets/` 的录屏文件名。补录片段可使用另一文件，但源分辨率必须相同。
- `q`：当前正常语速分镜的归一化进度，0–1 且递增。改文案后不必手动重算镜头时间。
- `x/y`：原始录屏坐标中的镜头中心，不能直接填写最终 1920×1080 画布坐标。
- `z`：缩放倍数。常用 1 → 1.4–1.7 → 1；先看全局、平滑推近、停留读取、再缩回。
- `anchor: "left"`：可选，表单放大时固定左边，避免把字段标签裁掉。

可省略 camera，得到完整画面。放大程度由目标元素尺寸决定。宽段落不要只按点击位置猛推近；保留正文完整行宽。不要每段都强制推近，稳定画面可给阅读留时间。

## 版式

横屏源录制 1440×800；输出 1920×1080，窗口内容 1560×866 放在 (180,98)。竖屏源录制 600×800；输出 1080×1920，内容 944×1258 放在 (68,368)。窗口标题栏 44px，摄像机只移动窗口内容。

竖屏使用真实窄屏布局重新录制。字段可左对齐小幅推近；长正文、评价、论文、联系信通常用 z=1 保留行宽。不能以居中放大切掉姓名首字或表单左侧标签。脚本拒绝明显不同纵横比的源素材，避免变形。

## 姓名与账号匿名

是否匿名按用户要求或敏感内容需要决定。当前导师案例要求只留姓氏，显示为“柴**”。这个姓名只是示例，不能写死到其他项目。

先清点原名、英文全名、倒序英文名等别名，以及搜索建议、表单、报告标题、正文、来源链接标题、生成信件和历史列表中的出现位置。录制期间用显示层替换或动态遮罩，避免原名先闪一帧：

- 文本节点：在 DOMContentLoaded 安装 MutationObserver，替换文本中的指定名字，跳过 script/style。
- 搜索输入：保留真实 `.value` 以保证查询正确；文字与光标设为透明，额外覆盖显示匿名姓名，随滚动和布局移动。不能把实际查询改为“柴**”再假装查到了结果。
- 已生成且只用于演示的联系信：显示层替换姓名，保留原有占位符与研究方向；不虚构用户学历或经历。
- 账号名称、额度、私人联系方式按展示需要遮盖，不打印认证信息。

若后期模糊遮盖，遮罩需要随页面滚动和缩放追踪。每段抽帧检查，重点看输入时、建议弹出时和生成结果首次出现时。也可用系统 OCR 检查全名残留；OCR 无命中不等于严格匿名证明，仍要目视检查。

## 编辑器与联系信镜头

生成后先展示主题和正文，再展示编辑/复制。自动 `scrollIntoViewIfNeeded()` 可能把长 textarea 居中到正文下半部：改为先把编辑器顶部滚到画面上方、`focus({preventScroll:true})`、移动鼠标，再稍后点击复制。必要时只在录制显示层适当降低 textarea 高度，保留可滚动原文。录下复制成功状态，不把复制说成已发送。
